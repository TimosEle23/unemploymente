# Account, notifications, CV, and copyable skills

## What will change
- Add a bell in the top bar with a compact notification panel for upcoming and overdue application actions, plus a clear “mark all read” action.
- Add a profile icon in the top bar that opens My Profile and account settings.
- Expand My Profile so the user can edit their name, headline, education, skills, and account email.
- Add secure password changing with current-password confirmation.
- Add a private “Latest CV” area to upload, replace, download, or remove one PDF/DOC/DOCX file.
- Make every displayed profile skill clickable, copying the exact skill to the clipboard with visible confirmation.

## Data and privacy
- Store the latest CV in a private, per-user storage area.
- Save only the CV filename and private storage path on the user profile.
- Restrict CV access so each signed-in user can only access their own file.
- Validate file type and size before upload.

## Interface
- Keep the existing dark retro JOBHUNT style and use the reference notification layout as direction.
- Allow long notification and skill text to wrap instead of clipping.
- Keep mobile controls icon-led and accessible with labels/tooltips.

## Verification
- Check desktop and mobile layouts.
- Test opening notifications, marking them read, navigating from one to its job, copying a skill, and profile/account form validation.
- Confirm CV upload controls and private access behavior.
